# 转盘界面视觉规范

用户的明确偏好：**像美团那样干净好用**，不要"AI 味的炫技"。信息密度高、层次清楚、少废话。

> 本地还装了 `frontend-design` 那个 skill，它主张"大胆鲜明的美学方向"。
> **本项目不采纳那种方向**（用户要的是克制、整洁、工具感），只在细节打磨上参考它。

## 设计令牌（`web/src/styles.css` 里的 CSS 变量）

```
--bg:#0b0e1f  --bg-2:#131834  --panel:rgba(255,255,255,.045)  --line:rgba(255,255,255,.1)
--text:#eef1ff  --muted:#9aa3c7  --brand:#6c8cff  --brand-2:#b388ff  --ok:#4ade80
```
主色渐变只用于"当前选中"和主按钮：`linear-gradient(135deg, #6c8cff, #b388ff)`。
**不要**给普通元素都上渐变或发光，会变成廉价感。

## 结构规范（三块，顺序固定）

```
① 地区：[选城市 | 随机城市 | 全省随机] + 城市 chips + 四个折叠维度（地铁/地区/商圈/商场）+ 已选标签
② 项目：[人工选 | 随机抽] + 全选行 + 按分组折叠的 chips
③ 过滤：排除已去过 / 人均 / 评分
→ 底部固定意图：当前选择摘要 + 主按钮「🎡 开始转动」
```

## 硬规则

- **折叠用原生 `<details>/<summary>`**，不要自己写状态机；默认展开常用维度（地铁、项目分组全展开）
- **默认全选**：项目进页面就是全选状态；区域默认"不限"
- **去掉解释性小字**：用户明确说过不要"无意义的注释解释"，只在真会踩坑处留一行
- **按钮可见性**：一级操作（开始转动）用 `button.primary` 大按钮；次要操作（导航、再转一次）用 `button.ghost`
- **移动端**：单列布局断点 `980px`；点击目标 ≥ 40px 高；chips 允许换行不横向滚动
- **中文排版**：字体栈 `system-ui, -apple-system, "PingFang SC", "Microsoft YaHei"`（中文用系统字体最好看，别为"独特字体"牺牲可读性）
- **数字用等宽感**：chip 上的数量用 `.chip-count` 小胶囊，不要和名称混在一起

## 改动后必须验证（不能只看代码）

```powershell
npm run build:web     # 注意沙箱需要提权，vite 要 spawn esbuild
npm run test:web      # 真实 Chrome：截图 + 抓控制台错误 + 跑通抽签
```
截图落在 `tests/out/ui-*.png`。**改样式后必须确认页面无控制台错误、元素数量正确**
（测试会检查：城市按钮、canvas、折叠维度数、全选勾选框等）。
